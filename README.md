### Projects

**[water-simulation](https://github.com/tailow/water-simulation)**: My Master's thesis project, a real-time ocean rendered in a single WGSL shader with Bevy. It covers waves and raymarched light both above and under the water.

**[reggz](https://github.com/tailow/reggz)**: A UCI chess engine written in Rust. It uses alpha-beta search with a transposition table, quiescence search and null-move pruning, and I test every change with SPRT matches. It plays on Lichess as [Reggz](https://lichess.org/@/Reggz).

**[room-monitor](https://github.com/tailow/room-monitor)**: Firmware for an ESP32, written in embedded Rust, that sends temperature and humidity readings over Wi-Fi to InfluxDB.

**[space-mystery](https://github.com/tailow/space-mystery)**: A game our team of four made in Unity for the GMTK Game Jam 2024. You can [play it on itch.io](https://karhut-games.itch.io/thetabytes).
